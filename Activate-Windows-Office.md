# Activate Windows/Office

Esta guía presenta métodos oficiales para activar Windows y Microsoft Office con una licencia válida.

> No ejecutes comandos de activación de sitios de terceros, especialmente comandos que descargan y ejecutan scripts remotos en PowerShell. Pueden modificar el sistema o comprometer el equipo, además de no proporcionar una licencia válida.

## Activar Windows

1. Abre **Configuración → Sistema → Activación**.
2. Revisa el estado de activación. Si tienes una clave de producto válida, selecciona **Cambiar clave de producto** e introdúcela.
3. Si tienes una licencia digital asociada a tu cuenta Microsoft, inicia sesión con esa cuenta. Si Windows no se activa después de un cambio de hardware, prueba el solucionador de problemas de activación.
4. Consulta la [ayuda oficial de activación de Windows](https://support.microsoft.com/windows/activate-windows-c39005d4-95ee-b91e-b399-2820fda32227).

## Activar Office o Microsoft 365

1. Abre una aplicación de Office, como Word, e inicia sesión con la cuenta Microsoft o laboral/escolar que tenga asignada la licencia.
2. Si compraste una clave de producto, canjéala en [Setup Office](https://setup.office.com/) con la cuenta que usarás para Office.
3. En una aplicación de Office, revisa **Archivo → Cuenta** para comprobar el producto y la cuenta activa.
4. Si necesitas ayuda, consulta la [guía oficial de activación de Office](https://support.microsoft.com/office/activate-office-5efba2b4-b1e6-4e5e-8e5e-1b7b2c1f4).

Usa una licencia válida adquirida en Microsoft o en un distribuidor autorizado. La activación técnica no reemplaza la licencia requerida.
